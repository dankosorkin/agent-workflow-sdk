# Tutorials

Two guided paths. Pick by how much you want to build.

The [Q&A agent quick start](qa-agent.md) is the short one: assemble a working documentation agent from the prebuilt `tool_loop` in a single sitting. It shows the payoff — streaming, durability, a human approval step — without building the machinery yourself.

The [optimizer tutorial](optimizer/index.md) is the long one. It builds a single system across ten chapters, one layer per chapter, starting from an empty file and ending with a durable, distributed task-planning optimizer served over HTTP. Each chapter adds exactly one idea and leaves you with a program you can run. This is the path if you want to understand the framework, not just use a prebuilt.

Start with the quick start for a feel of the result; take the optimizer tutorial to learn how every layer fits together.
