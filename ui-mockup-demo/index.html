Plan launcher

Five screens for designing, approving and launching plans on a local agent-workflow-sdk server. Each screen reads live data over fetch and SSE. Suggested order below.

1 · New plan from a requestDescribe a task; the designer drafts a plan and streams progress until it converges, hits the round limit, or is found not executable. 2 · Plans and launchLists real plans with their approval state. Review rights per step, approve, dry-run and launch. 3 · Run progressLive run status over SSE: answer a waiting run, resume a held run, see completed/partial/failed outcomes. 4 · All runsReal runs, the ones needing attention first. 5 · InventoryReal agents, backends and reserved fields. The edit panel is read-only with its approval-revoking warning.

Served by the workflow server at /ui/index.html (run python -m agentflow.workflow serve or serve(...), then open http://127.0.0.1:8765/ui/index.html). Fonts load from Google Fonts when online.
